# 技能流程缺口审查

只审查与本次真实故障有关的技能及必要引用。使用当前环境可定位的实际路径，不假定技能安装目录或专用调用工具。

## 判断问题

- **前提缺失**：环境、输入或权限条件错误，流程却继续执行。
- **失败路径缺失**：出错后遗漏停止、报告、恢复或待处理记录。
- **验证对象错误**：只看中间命令，未检查用户需要的结果。
- **知识路由错误**：把项目例外写成全局规则，或直接修改托管/自动生成记忆。
- **完成条件不实**：来源未覆盖、事项待确认时宣告全部完成。

每项说明：实际触发证据、缺口所在位置、用户影响、最小改法及行为验证场景。修正原规则位置，避免尾部堆叠补丁。仅在既有授权包含技能修改时执行，否则返回具体建议。
