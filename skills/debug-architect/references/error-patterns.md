# 常见调查方向

模式提供调查线索，不能替代实际证据。

| 类型 | 常见信号 | 需要核对的条件 | 可观察验证 |
|---|---|---|---|
| 语法或类型 | 解析失败、签名不匹配 | 入口和调用方是否一致 | 静态检查、最小导入或复现 |
| 配置或依赖 | 缺包、未知键、版本冲突 | 实际版本、作用域与锁文件 | 读取真实配置、核对官方契约 |
| 逻辑或状态 | 竞态、空值、状态卡死 | 边界条件、清理路径与并发假设 | 能重现原故障的行为测试 |
| 环境或权限 | 路径、编码、拒绝访问 | 实际路径、授权和外部状态 | 在目标环境验证所需能力 |
| 第三方服务 | 协议变化、限流、服务失败 | 响应、时效与接口版本 | 当前契约和最小请求结果 |
| 流程或验证 | 通过检查但产物错误 | 验证对象、引用与交付状态 | 检查实际产物和完整调用链 |

先保留证据再归类。修复后验证原故障已经消失；涉及变化中的外部契约时查当前权威说明。重试、降级或新增规则都应对应已经识别的失败条件。
